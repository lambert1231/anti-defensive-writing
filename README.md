# anti-defensive-writing

> 论文写作、修改、压缩、实验组织全流程中阻止**防御性写作**。
> 把论文当成一场学术发布会，而不是项目总结、实验日志或自我审查报告。

---

## 它解决什么问题

防御性写作是科研写作里最普遍、也最昂贵的坏习惯：作者在证据之外，主动替审稿人削弱自己的论文。典型症状：

- 摘要里塞满"**可能**""**潜在**""**或许**""**一定程度上**"——读者读完不知道作者到底相信什么；
- "**遗憾的是**""**虽然结果并不理想**""**我们承认**"——把审稿意见提前写进正文；
- "**仅**提升 3%""**未能**超过 Baseline""**效果有限**""**仍明显落后**"——用自己的手给自己的贡献贴低价标签；
- 贡献还没建立，就在引言里先列三条不足；
- 结论最后一段突然冒出一句自我否定。

这些句子不会让论文更"严谨"，只会让论文**更弱**。真正的严谨来自**事实层的边界**（适用前提、数据规模、统计不确定性），而不是**表达层的道歉**。

本 skill 的目标只有一个：**找到这项工作真正成立的优势，围绕它组织全部材料，并用直接、清晰、有力的语言把这个优势讲到足够清楚。**

---

## 四条铁律

1. **识别并去除防御性表达**：不必要的过度免责声明、预设反驳的道歉式措辞、冗余的模态犹豫词（可能、或许、潜在）、自我贬低的消极限制。
2. **主张前置**：优先陈述核心论点、创新贡献与研究发现，再谈条件、边界与代价。
3. **不误伤严谨性**：准确保留必要的科学严谨性、方法边界与适用范围，但将其客观置于恰当的分析语境中，而不是作为辩解性铺垫。
4. **语言风格**：直接、清晰、有力、以论点为核心（claim-forward）。

> **红线**：本 skill 只做**表达层**的强化，**不改变事实层的真值**。不得新增未提供的证据、不得修改数据、不得删除影响结论成立的科学事实、不得把不确定的结论写成确定的。

## 两种工作模式

| 模式 | 触发情形 | 动作 | 改动幅度 |
|---|---|---|---|
| **A. 写作 / 重构模式** | 从零起草，或允许大改结构 | 重建叙事与语言 | 大改，可重排章节、重选主结果 |
| **B. 逐处诊断模式** | 给出现成文字，要求"检查 / 指出 / 改一下" | 逐句定位防御性表达并给出改法 | **最小改动**：保结构、保用词习惯、不整段重写、无问题处不动 |

### 模式 B 的输出格式

```
【第 N 处】
原句：<原文，一字不改地引用>
类型：C 冗余模态犹豫词
问题：<一句话说明它削弱了什么>
改法：<改写后的句子>
改动说明：<删了哪个词 / 换了哪个词，为什么最小改动即可>
```

诊断结束后给出统计（`共 N 处，A 类 x / B 类 y / C 类 z / D 类 w`）并指出最该优先修的三处。
若通读后未发现防御性表达，**直接说明未发现，不为凑数而改动**。

## 防御性表达四类清单

| 类别 | 特征 | 高频词 | 处理动作 |
|---|---|---|---|
| **A 过度免责声明** | 主动声明本工作"不适用/不能保证"，而这些限制既非读者关切也不影响核心结论 | 可能不适用于所有场景、本文不声称、仍有诸多不足、受限于时间 | 删除 → 具体化 → 收窄为条件性陈述 |
| **B 预设反驳的道歉式措辞** | 在贡献尚未建立时抢先替审稿人写批评 | 遗憾的是、令人意外的是、我们承认、并不理想 | 删情绪词与道歉语，只留客观事实 |
| **C 冗余模态犹豫词** | 在已有证据支撑的结论上叠加不确定语气 | 可能、或许、潜在、似乎、一定程度上、倾向于、有望 | 无数据支撑则删；有支撑则换**量化表述** |
| **D 自我贬低的消极限制** | 用缩小性副词或否定动词给自己的贡献贴低价标签 | 仅、只、未能、无法、效果有限、仍明显落后 | 删除副词；约束改写成可行性证据；权衡改写成条件性事实 |

**边界 vs 辩解的判据**：这句话是在帮读者正确使用结论（保留），还是在替反方论证、压低本文价值（删）。
核心操作是 **保留事实 → 移动位置 → 去掉语气**：严谨性内容集中到讨论 / 局限性节，绝不出现在摘要开头、引言贡献之前、结论末段。

## 设计原则

- **不平均展示**：不追求"所有数据集、所有指标全面领先"。说服力来自主张与证据高度一致，而不是比较项目数量最多。
- **不主动示弱**：不替审稿人总结弱点，不把局部现象写成普遍缺陷，不主动扩大攻击面。
- **不写实验流水账**：每个实验必须承担明确论证职责（证明有效 / 证明关键机制 / 证明场景价值 / 排除替代解释），不承担职责的实验删掉或重新设计。
- **允许彻底重构故事**：现有结果无法支撑原始叙事时，重新定义问题、重排贡献、重选主结果，而不是围绕原叙事防守。
- **遇到不理想材料的优先级阶梯**：删除 → 缩小主张 → 换评价维度 → 解释为权衡 → 重组实验 → 重新定义故事 → 只有在无法回避且确实影响核心结论时才做必要说明。
